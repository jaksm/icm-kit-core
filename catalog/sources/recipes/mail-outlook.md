# Outlook.com and Microsoft 365

Read `core/RECIPES.md` first: nobody has run this. Menu names change; trust what is on the owner's screen over this text.

Rules live in Settings, Mail, Rules. There is no import of a rule file in the web app. Rules move mail into **folders**, not labels: one message lives in one place, so "label and keep in inbox" becomes a **category** plus no move. Create each rule by hand with the owner, in the order of `senders.csv`, because rules run top to bottom and "stop processing more rules" is on by default. With an organization account an administrator may have disabled rules that forward or redirect; sorting rules are unaffected.

Proof, as always: after creating the rules, open the list and count them, then wait for one real message and see where it landed.
