# iCloud Mail

Read `core/RECIPES.md` first: nobody has run this. Menu names change; trust what is on the owner's screen over this text.

Rules exist only in the web app at icloud.com, Mail, Settings, Rules, and they are few and simple: a condition on sender or subject, and move to folder, mark as read, or forward. No import, no labels, and a modest limit on the number of rules. With more than a couple of dozen senders it is worth grouping by domain. Rules made in the Mail app on a Mac run only while that Mac is on, so they are not what is wanted here.

Proof, as always: after creating the rules, open the list and count them, then wait for one real message and see where it landed.
