# Proton Mail

Read `core/RECIPES.md` first: nobody has run this. Menu names change; trust what is on the owner's screen over this text.

Filters are in Settings, Filters, and paid plans can write them as Sieve, which allows generating them from `senders.csv` as for Fastmail. The free plan limits the number of filters. Mail is end to end encrypted, so **no connector can read this mailbox** unless the owner runs Proton's Bridge on their computer and the agent reads through it locally; from a cloud session it cannot be reached at all. Expect sorting to work and the morning review not to.

Proof, as always: after creating the rules, open the list and count them, then wait for one real message and see where it landed.
