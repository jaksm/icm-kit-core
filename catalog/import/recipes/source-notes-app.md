# A notes app (Notion, Obsidian, Apple Notes, Evernote, Keep)

Read `core/RECIPES.md` first. One real import from one such app stands behind the warnings below; the steps were not rerun.

Prefer reading through a connector when the harness has one, because it keeps titles, dates and the
page tree. Otherwise ask the owner for an export (markdown or HTML, with attachments) into a folder
**outside** the ICM, and read from there. Nothing from the export folder is copied wholesale.

Known to bite: links to images in an export or an API response are often signed and **expire
within minutes**; download an image right after the fetch that named it, or it is gone. Look at
every screenshot before it is committed: screenshots are where passwords hide. Databases and boards
flatten into many tiny pages; inventory them as one item per database, not per row.
