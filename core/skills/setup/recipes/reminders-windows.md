# Reminders on Windows

Microsoft To Do is the usual one and syncs to the phone through the Microsoft account. The agent
reaches it only through a connector for Microsoft 365, if the harness has one and the owner has
connected it. Without that: `reminders-calendar.md` with their Outlook or Google calendar.

Do not build a local script against the To Do app: it has no command line, and a script that drives
the window breaks on the next update.
