# Reminders through a calendar

Works from anywhere the agent has a calendar connector, including a cloud session, and shows up on
every phone. The price: an event is not a checkbox.

1. The owner creates one calendar used only for this ("ICM"), so these never mix with their appointments.
2. A reminder is an all-day event on the day it becomes relevant, titled with the next move, the
   note in the description. Nothing is invited, nothing is shared: an event other people can see is an
   outside action and needs the owner's word.
3. "Done" is the owner deleting the event, or telling the agent. The catch-all and "today" lists
   become: events without a day go on Monday of next week; "today" is today.
4. Proof: create "ICM test, delete me" for today and ask whether it shows on the phone.
