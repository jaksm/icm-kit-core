Themes

One system, many looks. A theme is only token values: palettes, type sets, shape, a few effects. Pick one, make a palette from a color, change the type; this whole page is the preview, and every choice is held to the same contrast gate as the build.

A calm interface for things you wrote down.

icm-ui is what an agent builds pages from: a morning feed, a spending view, a plan for a trip. It shares a brand with the kit's site and none of its volume. The site has to stop a stranger; these pages are opened every day on a phone and must get out of the way.

Kept from the site

Cold paper and blue-black ink, ultramarine, the yellow marker, Archivo and IBM Plex Mono, hard edges, a shadow that is never blurred.

Turned down

No color blocks, no giant type, no 3D. Paper everywhere, 1.5px borders, 8px corners for thumbs, blue only on what can be acted on.

Why “calm brutal”

Honest construction reads as trustworthy for private data: you can see what is a button, what is a fact and what is yours to answer.

Rules every page keeps

A shadow means “press me”

Only pressable things carry the hard shadow, and pressing moves them into it. What is only read is flat.

Yellow means “this one”

The marker is for what is current, chosen, or changed. One marked thing per screen if possible. Never decoration, and never alone: yellow on paper is a weak contrast, so the marked thing also gets an ink bar.

Blue means “you can act”

The primary action, a link that can be followed, the filled part of a gauge. Never a background.

Hover never resizes text

No weight, width or size change under a pointer. Color, ground and the marker may change.

Nothing feels stuck, nothing fades in

Input answers at once. Content you must read appears, it does not dissolve into view.

Motion answers the person

Press, choose, open, confirm. A small spring on the thing that received input. All of it still under reduced motion.

1. Primitives

Everything else is assembled from these. Each value is a token in tokens/; change it there and this page follows.

Color light: decideddark: proposed

Four colors with one job each. Text on paper is ink at three strengths. Lines are visible on purpose.

State and data proposed

State colors mean “this changes what you do”. The categorical ramp is for charts and category dots; rank decides the slot and the tail is grey, so a chart never needs a legend of twelve hues.

Type decided

One variable grotesque for what is read and what is operated. Six sizes, nothing under 13px, three weights. The mono is only for file paths, file contents and figure captions: if it is not a file, it is not mono.

Space proposed

On a phone

--gutter 16px at the edges, --s-3 inside a row, --s-5 to --s-6 between groups, --s-7 between sections. A touch target is never under --tap 48px.

Generous vertically

When in doubt, add space above a heading, not inside a card.

Surfaces decided

A component never reads a color directly. It reads --c-*, and the surface class decides what those mean, so the same component sits on paper and on a photograph.

.on-photo: fixed light text on a scrim, no hard shadows

The marker decided

Current, chosen, changed

Tap a row: the marker moves, nothing else does. The same yellow marks the chosen option of a question and the number that changed since yesterday: 4 points over last month.

Micro-interactions proposed

Press

Moves into its shadow, 80ms. Used hundreds of times a day, so that is all it does.

Hold to confirm, then celebrate

What changes something outside is confirmed by holding: the marker fills the button from the left, letting go early drains it. It is a question, never a red warning. Success is rare and earned, so it throws a little paper. This is the real icm-action.

Choose

The marker lands with a small spring. The label never changes weight.

Focus

The field grows a blue shadow: “you are typing here”.

Open

Details pull out like a drawer, with momentum.

Flights booked for the 14th. The rental car is still open.

How often decides how much

Rare (a confirmed action succeeds): expressive. Daily (open details, choose): subtle, under 400ms. Constant (press, scroll, type): instant. From the keyboard: never animated; holding becomes a second press.

Reduced motion

Transitions are off and the burst does not exist. Holding becomes “sure?” and a second press, so nothing has to jump.

Buttons, links, icons decided

Icons

Drawn inline at 1.6 stroke, sized by the font size, colored by the text.

2. Components, taken apart

A component is a fixed composition of primitives with one job, and it renders nothing when its data is missing. None of them has an outer margin: the stack that holds them decides the space. The tables come from schema.json.

Parts of today’s artifacts, as compositions

The feed, the expenses page and the graph each carry markup of their own. Every one of those parts can be written with the primitives above; these are the recipes the templates move to.
