# 0.6.0 to 0.7.0

Nothing moved. Every page is rebuilt in the one theme the library now carries (Aquarium, Pearl, Manrope), so
rebuild and republish your pages after the update; they look different, light and dark both.

`_config/theme.json` and `_config/themes/` are no longer read. Delete them if you have them. If you ran from an
untagged checkout between 0.6.0 and 0.7.0 you may have `pages/theme.html`: delete it, nothing builds it any more.

If you keep a changed page template in `_config/overrides/`, check it in both schemes: it should write no border
color, shadow or font of its own.
