# 0.2.0 to 0.3.0

## What changed and why

Recipes became a system with a trust tier (`core/RECIPES.md`), so the kit can say honestly which
paths were run and which were only written. Setup gained steps 09 (sources), 10 (reminders) and 13
(routines). The catalog has its first two workflows, `sources` and `morning-review`.

## Moved or renamed

Nothing.

## Outside core/

Required for an ICM made from the template before 2026-09-20: in `.githooks/pre-commit` set
`LINK_CHECK_SKIP=".git core"`. Core's documents now point at workflows that are only present once
they are installed from the catalog, so without this the owner's link check fails on files that are
not theirs, and **every commit is refused**. Core is checked upstream.

Optional:

1. `<release>/install.sh . --add sources --add morning-review`, then each workflow's `setup.md`.
2. An ICM that already sorts mail its own way: put the existing rules into
   `_config/sources/senders.csv` first, run `morning-review` as a **dry run** beside the old routine
   for a few days, compare the two records, and only then retire the old one.
3. `_config/reminders.json` if the reminder channel should be used by `core/scripts/remind.sh`.

## Verify

```bash
<release>/install.sh . --status                                  # 0.3.0; the catalog lists sources and morning-review

```
