# 0.5.0 to 0.5.1

## What changed and why

`install.sh` is now tested, and one fault the tests found is fixed: taking out a workflow whose files
you had edited deleted the edits and then refused the install. It is now refused first; with
`--force` the folder stays beside the others as `core/workflows/<name>.local`, which no update touches.

## Moved or renamed

Nothing.

## Outside core/

Nothing.

## Verify

```bash
<release>/install.sh . --status     # 0 locally edited files after the update
```
