# 0.3.0 to 0.4.0

## What changed and why

Setup gained step 12 (import). The catalog has `import` and `expenses`. `core/scripts/remind.sh` is
now verified on macOS. Nothing that worked in 0.3.0 moved.

## Moved or renamed

Nothing.

## Outside core/

Nothing is required. Optional: `<release>/install.sh . --add import --add expenses`, then each
workflow's `setup.md`. An ICM that already keeps a monthly aggregate of spending can point
`monthly_file` and `columns` in `_config/expenses.json` at it and build the page beside its old one.
An existing statement parser stays where it is, in the owner's `skills/`: it is what the recipe would have produced.

## Verify

```bash
<release>/install.sh . --status
for s in categorize aggregate build-expenses-page; do python3 core/workflows/expenses/scripts/$s.py --check; done   # after --add expenses
```
